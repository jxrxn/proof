What is this proof, and what happens next?

1. Hash created locally. A SHA-256 fingerprint of your file or text was computed on your device. The original was never uploaded.

2. Hash submitted to OpenTimestamps. Only the hash was sent. In return you received an .ots file — your initial proof. It does not yet contain Bitcoin verification data.

3. Bitcoin anchoring (usually 1–6 hours). OpenTimestamps commits your hash to the Bitcoin blockchain — it is written into a Bitcoin transaction.

4. OpenTimestamps proof. Once anchored, your initial proof becomes a full OpenTimestamps proof — now containing Bitcoin verification data — that anyone can verify against the Bitcoin blockchain, without trusting you, me, or OpenTimestamps.

To check the proof, use the Verify panel, run ots verify FILE.ots, or visit opentimestamps.org.

Timestamp any text or file. This app creates a SHA-256 hash on your device and submits only that hash to OpenTimestamps. OpenTimestamps then anchors it to the Bitcoin blockchain, usually within 1–6 hours.

Your original file or text is not uploaded. Only the cryptographic hash is submitted for timestamping, and a hash cannot be reversed to reveal the original contents.

Right after creation you hold an initial proof, which does not yet contain Bitcoin verification data. Once Bitcoin anchoring completes it becomes a full OpenTimestamps proof that can be independently verified — demonstrating that the file or text existed at that point in time, while preserving privacy. Save your proof so you can do this later.

Using this app is free. OpenTimestamps calendar servers are free to use and rely on donations. Learn more at opentimestamps.org.
