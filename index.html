What is this proof, and what happens next?

1. Hash created locally. A SHA-256 fingerprint of your file or text was computed on your device. The original was never uploaded.

2. Hash submitted to OpenTimestamps. Only the hash was sent. In return you received an .ots file – your initial proof. It does not yet contain Bitcoin verification data.

3. Bitcoin anchoring. OpenTimestamps combines many submitted hashes into a shared cryptographic commitment, which is anchored to the Bitcoin blockchain. Your .ots file contains the cryptographic path needed to prove that your hash was included in that commitment.

4. OpenTimestamps proof. Once the commitment has been anchored, the initial proof can be completed with the Bitcoin verification data, turning it into a full OpenTimestamps proof. Anyone can then verify it against the Bitcoin blockchain without trusting you, me, or OpenTimestamps. You do not need this app to verify it.

The proof file (.ots) contains only the hash and can be shared freely. The proof package (.zip) also contains a copy of your original file.

To check the proof, use the Verify panel, run ots verify -f ORIGINAL_FILE PROOF.ots, or visit opentimestamps.org.

Proof creates a SHA-256 hash of your text or file on your device. Only this hash is submitted to OpenTimestamps – your original content is never sent.

OpenTimestamps combines many submitted hashes into a shared cryptographic commitment, which is later anchored to the Bitcoin blockchain. Your .ots file contains the information needed to connect your hash to that timestamp.

Keep the original file or text together with its .ots file. Once the Bitcoin timestamp has been established, the proof can be independently verified at any later time. You do not need this app to verify it. The .ots file uses the open OpenTimestamps protocol and can be verified with compatible OpenTimestamps software.

Using this app is free. OpenTimestamps calendar servers are free to use and rely on donations. Learn more at opentimestamps.org.
